Syndra

Made by Fud0o0 & Ax0-0 — Syndra is a customized Hyprland setup with integrated security tools.

Everything you need for penetration testing, defense, or CTF challenges. Fast, minimal dependencies, fully themeable.

GitHub
Quick Install
$ git clone --depth 1 https://github.com/Fud0o0/Syndra.git ~/.config/SyndraShell && bash ~/.config/SyndraShell/scripts/secure-install.sh purple
25 GB requis

Requires Arch Linux with Hyprland

Pour désinstaller: bash <(curl -sL https://raw.githubusercontent.com/Fud0o0/Syndra/main/uninstall) --full

Features

Lightweight

Hyprland is snappy. Everything responds instantly. No bloat.

Tools Included

Nmap, Burp, Metasploit, Wireshark, and more. Choose your profile (Red/Blue/Purple/CTF).

Pick Your Colors

Red, Blue, or Purple. Switch themes without restarting. Wallpapers included.

One Command Install

Clone, run, done. Dependencies handled. Works on Arch with Hyprland.

Commands & Shortcuts

Built for Efficiency

Syndra Commands

  • syndra update Pull latest from GitHub. Updates checked for integrity. Done.
  • syndra restart Restart the shell. No logout needed.
  • syndra menu App launcher. Hit SUPER+A. Categories. Search. Clean.
  • syndra provisional GTK interface for tweaking config without Hyprland.

Keyboard Shortcuts

  • SUPER + A Menu. Apps and categories. Search works.
  • SUPER + D Dashboard. System info and quick stats.
  • SUPER + R Terminal. Kitty. Ready to go.
  • SUPER + L Lock. Hyprlock. Secure.
